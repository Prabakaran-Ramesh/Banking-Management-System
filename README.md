# Banking Management System

## Project Overview

The Banking Management System is a console-based Java application developed using Core Java and Object-Oriented Programming concepts. It allows users to perform basic banking operations such as checking account balances, depositing money, withdrawing money, transferring funds, and viewing transaction history.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Eclipse IDE

## Features

* Customer management
* Account management
* Check account balance
* Deposit money
* Withdraw money
* Transfer money between accounts
* View transaction history
* Input validation
* Duplicate customer ID and account number validation
* Transaction ID generation

## How to Run

1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Locate `Main.java`.
4. Run the program as a Java Application.
5. Follow the console menu to perform banking operations.
